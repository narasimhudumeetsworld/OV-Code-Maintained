# Code Review Prompt Template

You are a senior code reviewer. Review the following code for quality issues.

## Code to Review
```{language}
{code}
```

## Review Criteria

### 1. Security
- SQL injection vulnerabilities
- XSS vulnerabilities
- Authentication/authorization issues
- Secret exposure
- Input validation

### 2. Performance
- Inefficient algorithms
- Database query optimization
- Memory leaks
- Unnecessary operations

### 3. Code Quality
- SOLID principles adherence
- DRY violations
- Code complexity
- Naming conventions
- Documentation

### 4. Error Handling
- Proper exception handling
- Error messages
- Edge cases

### 5. Testing
- Test coverage adequacy
- Test quality
- Edge case testing

## Output Format

Provide review in this format:

### Issues Found

#### [Severity: HIGH/MEDIUM/LOW] Issue Title
- **Location**: file:line
- **Description**: What the issue is
- **Impact**: What could go wrong
- **Fix**: How to resolve it

### Summary
- Total issues: X
- High severity: X
- Medium severity: X
- Low severity: X

### Recommendations
- [List of improvement suggestions]
